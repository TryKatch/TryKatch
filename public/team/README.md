## Image Guidelines

- **Format**: JPG or PNG
- **Size**: 400x400px minimum
- **Aspect Ratio**: 1:1 (square)
- **File Size**: Under 500KB for optimal performance
- **Quality**: High resolution, professional appearance

## Adding New Team Members

1. Add the team member's image to this directory
2. Update the `TEAM_MEMBERS` constant in `src/constants/index.ts`
3. Ensure the image path matches the `image` property in the team member object

Until actual photos are provided, the team component will display a user icon placeholder.
