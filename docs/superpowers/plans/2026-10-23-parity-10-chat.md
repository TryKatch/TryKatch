# TryKatch Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task, with explicit file ownership and the existing single review workflow.

**Goal:** Add authorized organization messaging with channels/DMs, threads, attachments, mentions, reactions, pins, search and typing.
**Architecture:** Optional five-layer organization module owns durable chat and resource authorization. Required Documents handles opaque attachments; Notifications is optional for mention inbox. Host realtime/cache deliver authorized ephemeral updates and reconcile from durable APIs.
**Tech Stack:** Existing stack, PostgreSQL full-text search, phase 3 attachment contracts, E3 and S1/S2/S3.
**Spec:** [Design](../specs/2026-10-23-feature-parity-design.md); [roadmap](2026-10-23-feature-parity-plan.md).

## Global Constraints

Apply all roadmap constraints; paths are relative to `templates/trykatch/`; new names are proposed. Full parity profile includes Notifications. RLS enforces organizations; channel membership is an additional mandatory application policy for reads, writes, search, notifications, attachments and realtime.

## Review Focus

- A valid organization member outside a private channel cannot observe it through any API, search, Documents or push path.
- Concurrent DM creation and message retries produce one logical conversation/message.
- Membership revocation and organization switching terminate future channel delivery/access.
- Tombstoned messages preserve thread consistency without retaining unauthorized visible content.
- Typing/presence is ephemeral and throttled; the durable message ledger is authoritative.

Permissions `chat.read`, `chat.write`, sensitive `chat.manage` and `chat.moderate`; membership further narrows access. Use per-conversation server order/cursor and logical client message identity.

- [ ] Freeze channel discovery/join, ownership/admin transfer, edit/delete and archive rules in `docs/specs/chat.md`; proposed reference requires explicit current membership for all private content. No implicit organization-wide discovery of private DM names/members.

- [ ] Test account removal and channel admin transfer against last-admin rules chosen in the module spec. Re-check access in Application even when an HTTP/realtime caller previously checked it.
- [ ] Verify Chat unit/architecture tests, `ChatAuthorizationIntegrationTests`, relevant module/RLS/idempotency tests and common exit.

## H3: Add full-text search and ephemeral realtime behavior

**Files:** Chat Application `ChatSearch.cs`, `TypingUseCases.cs`; Infrastructure PostgreSQL search model/index/query and realtime audience adapter; host tests `ChatSearchRealtimeIntegrationTests.cs`, unit `ChatSearchPolicyTests.cs`, `TypingThrottleTests.cs`.

**Interfaces:** `Chat_SearchMessages`, typed realtime notifications for conversation/message invalidation and ephemeral typing; search cursor/query filters always join current authorized membership. Typing cache keys include environment/application/organization/conversation/actor and expire quickly under an explicit host limit.

- [ ] Test keyword search by nonmember and revoked member, deleted/archived policy, pagination ties, cross-organization text and SQL/raw query policy. Search result snippets obey exactly the same visibility as normal history.
- [ ] Add PostgreSQL full-text index/query with membership predicates; use an explicitly documented language/tokenization default with a supported fallback. Do not introduce an external search service for reference parity.
- [ ] Test current-authority connect/subscribe/delivery, membership removal after connect, two replicas, duplicate/out-of-order pushes, slow clients, backplane outage and reconnect cursor catch-up. No newly emitted private event reaches a revoked audience.
- [ ] Add throttled ephemeral typing, clearing on expiry/disconnect and no durable typing ledger. Realtime send intent does not replace S3/HTTP/DB mutation checks; choosing HTTP sends plus realtime receive is a supported simpler implementation.
- [ ] Verify `ChatSearchPolicyTests`, `TypingThrottleTests`, `ChatSearchRealtimeIntegrationTests`, S2 regression cases and common exit.
