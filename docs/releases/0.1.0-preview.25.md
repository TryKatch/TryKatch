# Trykatch 0.1.0-preview.25

Both published packages, `Trykatch.Templates` and `Trykatch.Cli`, use this version. The template's short name remains `trykatch`; no package or template identity has been renamed.

## Developer experience

- Five bundled project-local development skills and English/French onboarding guides, discoverable in generated README/task-router files and generation-time instructions.
- A concrete first-run-to-first-feature Equipment walkthrough, including backend-only cookie login, refreshed antiforgery, membership discovery and workspace selection with curl.
- Source-local doctor, locked setup and honest runtime status; validated, read-only installed module facts.
- Generated module pagination, version-protected CRUD/lifecycle operations, safe frontend conflict recovery and typed table contributions.
- Fresh packed backend/React qualification, including real PostgreSQL catalog isolation with skipped/zero-test rejection and explicit manual acceptance boundaries.

## Install or update

```bash
dotnet tool install --global Trykatch.Cli --version 0.1.0-preview.25
# Already installed? Use: dotnet tool update --global Trykatch.Cli --version 0.1.0-preview.25
dotnet new install Trykatch.Templates@0.1.0-preview.25
```

Template updates affect newly generated applications; they do not retrofit customized existing applications. Equipment is an educational scaffold, not a completed rental workflow. This release does not include the separate, uncommitted in-app AI Help runtime work. No additional AI account/key is required for repository-based developer onboarding.
