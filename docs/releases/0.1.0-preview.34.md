# TryKatch 0.1.0-preview.34

This preview adds a minimal starter for teams building their first business module. Generate it with the matching CLI and template packages.

```sh
dotnet tool install --global Trykatch.Cli --version 0.1.0-preview.34
dotnet new install Trykatch.Templates@0.1.0-preview.34
trykatch new Katch --module-profile minimal
```

The minimal profile starts with an empty module catalog and retains the example module sources. Omitting `--module-profile` generates the full starter. The generated minimal React application has browser coverage for administrator sign-in and the absence of example API routes.

## Platform and operations

- The template targets .NET 11 and C# 15, with Aspire 17, EF Core 11, Npgsql 11 and PostgreSQL 19. Local object storage uses RustFS 1.0.7.
- The production migrator serializes deployments and checks runtime roles, grants and row-level security. Existing PostgreSQL 18 installations require a major-version upgrade. Back up before changing the server image and use the [database runbook](../../templates/trykatch/docs/database.md).
- Newly generated applications include organization-scoped background work and caching, queued email, realtime invalidation and history, idempotent mutations, feature availability and organization quotas.

Installing a new template affects future generated applications. Teams upgrading an existing application should review the platform, migration and module changes before applying them.
