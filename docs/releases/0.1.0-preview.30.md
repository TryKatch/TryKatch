# Trykatch 0.1.0-preview.30

## English

Coordinated CLI/template preview candidate correcting the floating-label regression reported after preview.29. This document describes the candidate; package availability requires successful exact-main CI, sealed release qualification and publication.

```bash
dotnet tool update --global Trykatch.Cli --version 0.1.0-preview.30
trykatch update --version 0.1.0-preview.30
# First CLI installation: use dotnet tool install instead of update.
```

Generic authentication/dialog form CSS was turning floating labels into grids, placing the required marker on a second line and displacing the label. Those rules and the role-identity rule now exclude labels owned by the shared floating control. The exclusion preserves native picker/checkbox specificity; no API, authorization, migration or dependency behavior changes.

- Standard inputs remain 38 px, search inputs 34 px and buttons retain their existing size and branding.
- Associated labels and required markers remain on one line. Labels float on focus, stay above filled values and return inside after clearing and blur, without painted backgrounds or an extra input focus ring.
- Real sign-in stories cover English, French and dark mode. New host-container stories cover text, textarea and password controls inside authentication, dialog, profile and role forms.
- English/French shipped guides and public documentation explain the styling boundary and required integration checks. Installation commands and coordinated package metadata target preview.30.

Local correction checks passed: 115 Chromium Storybook interaction/accessibility checks; workspace typecheck and frontend unit tests; production, Storybook and documentation builds. A freshly packed test template generated a new React application whose 25 focused form/authentication checks and production build passed. Its production sign-in page was checked at 320/768/1440 px in light/dark and English/French, including focus, fill, blur and clearing. These are focused frontend results, not new backend-security evidence.

The release pipeline must separately qualify the exact release package pair before trusted publication. The complete Storybook coverage inventory, automatic generated CRUD/workflow stories and rollback qualification, remaining states/server pagination and full application-wide responsive/theme/locale matrix remain unfinished. This focused sign-in matrix does not close that broader roadmap. The preview is not an enterprise certification.

Updating the installed template does not rewrite existing generated applications. Newly generated React projects include the correction; customized existing applications require a reviewed source change.

## Français

Candidat de préversion coordonnée CLI/template corrigeant les libellés flottants signalés après preview.29. La disponibilité exige la CI du commit exact sur main, la qualification scellée et la publication.

```bash
dotnet tool update --global Trykatch.Cli --version 0.1.0-preview.30
trykatch update --version 0.1.0-preview.30
```

Pour une première installation, utiliser `dotnet tool install`. Les styles génériques transformaient le libellé en grille et plaçaient l’astérisque sur une seconde ligne. Les règles d’authentification, de dialogue et de rôle excluent désormais les libellés du contrôle partagé, sans modifier la spécificité des sélecteurs natifs ni les autorisations serveur.

Les tailles compactes (38 px, recherche 34 px), les boutons et la marque restent inchangés. Les libellés sont associés, transparents et sur une seule ligne ; ils flottent au focus et après saisie, puis reviennent à l’intérieur après effacement et perte du focus. Les stories testent la vraie connexion et les contrôles dans leurs conteneurs hôtes. Les guides et commandes d’installation anglais/français sont synchronisés.

Les 115 tests Storybook, le typage, les tests frontend et les builds locaux ont réussi. Une application React générée depuis un paquet de test fraîchement construit a réussi 25 tests ciblés et son build de production. Sa page de connexion a été vérifiée en clair/sombre, anglais/français et 320/768/1440 px. Cela ne remplace pas les tests de sécurité backend ou la qualification des paquets exacts de publication.

La couverture exhaustive du catalogue, les stories automatiques CRUD/workflow et leur rollback, les états restants et la matrice complète de l’application restent à terminer. Ce n’est pas une certification entreprise. Mettre à jour le template ne réécrit pas les applications existantes ; les nouveaux projets React reçoivent la correction, les projets personnalisés nécessitent un changement source revu.
