# Trykatch 0.1.0-preview.26

This coordinated preview versions `Trykatch.Templates` and `Trykatch.Cli` together. The product name remains **Trykatch**, package IDs remain unchanged and the template short name remains `trykatch`.

## Changes

- Privacy-safe HTTP completion logging now records matched route templates and exceptional/client-aborted outcomes, preserving exception propagation and omitting raw paths, queries and exception secrets.
- API-only changes select same-checkout API/client contract verification.
- Generated applications receive a .NET 10.0.301 SDK policy with patch roll-forward within 10.0.3xx, pinned workflow actions and first-restore-safe NuGet cache configuration. See the bundled English/French dependency-reproducibility guides.
- Release qualification consumes one prepared template/CLI package pair. Publishing downloads those exact bytes, checks digest/size/commit/version/run/source-CI identity before obtaining credentials, and never rebuilds. Stable publication fails closed while hardening gates are open or configured approval is absent.
- The readiness ledger now distinguishes immutable preview.25 evidence, verified engineering follow-through and still-open production acceptance.

## Qualification and scope

[PR #109 CI](https://github.com/TryKatch/TryKatch/actions/runs/35234520274) passed 18/18 jobs, **282 source unit + 247 PostgreSQL integration tests**, zero failures/skips, generated production/browser journeys, template/blueprint matrices and actual candidate transfer. These are implementation evidence, not the final release manifest. Publication additionally requires successful exact-commit main CI and tag qualification. The GitHub release carries the qualified package manifest, SHA-256 checksums and SBOM after successful publication.

This remains a preview, not production-ready or an RC. Administration concurrency, end-to-end telemetry/alerts, full locked-restore and OS/IDE qualification, manual accessibility/UAT, recovery/load acceptance and independent final review remain open. The separately uncommitted in-app AI Help runtime and role-management UX branch are not included.

## Install or update

Run these only after this version appears in the published release/NuGet feed:

```bash
dotnet tool install --global Trykatch.Cli --version 0.1.0-preview.26
# Already installed? Use:
# dotnet tool update --global Trykatch.Cli --version 0.1.0-preview.26
dotnet new install Trykatch.Templates@0.1.0-preview.26
```

Updates affect newly generated applications; they do not overwrite customized existing applications. Existing projects must deliberately adopt and test SDK/workflow/runtime changes. No credential or AI API key is required for repository-based developer onboarding.
