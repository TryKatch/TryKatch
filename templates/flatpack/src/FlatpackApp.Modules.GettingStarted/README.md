# Flatpack Getting Started module

This reference package demonstrates Flatpack's explicit full-stack module contract. It contributes a secured organization endpoint, a code-defined permission, a React route and navigation item, and a permission-gated extension to the Projects screen.

The package is part of the canonical template and is intended as the starting shape for source and future registry modules. See `docs/modules.md` in a generated application for activation, disablement, data, and security rules.
